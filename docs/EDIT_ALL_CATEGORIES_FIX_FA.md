# اصلاح مشترک صفحه ویرایش همه دسته‌ها — ۷ نوامبر ۲۰۲۶

مبنای اصلاح: ZIP لحظه‌ای Fazajoo_FOR_CHATGPT(20261107-200756).zip، پس از RT-02.

## اصلاحات
- عنوان صفحه ویرایش و درخواست به جای «پارکینگ» ثابت، برای هر یک از ۹ دسته براساس category واقعی آگهی ساخته می‌شود؛ حتی اگر مسیر قدیمی /edit-parking/:id باقی بماند.
- متن اطلاعات پایه، نمونه عنوان، پیش‌نمایش (عنوان، شهر، تصویر و شرح درخواست) و راهنمای تکمیل درخواست دیگر برای همه دسته‌ها «پارکینگ» نشان نمی‌دهد.
- اصلاح فاصله سربرگ و فرم ویرایش برای **همه عرضه‌ها** به‌جای فقط پارکینگ، در دسکتاپ و موبایل؛ و اصلاح خوانایی متن کوچک کارت اطلاعات سربرگ در زمینه روشن. ویرایش تقاضا جریان مخصوص خود را حفظ می‌کند.
- دسته «ویلا» به برچسب دسته در کارت آگهی اضافه شد (Fallback در نبود categoryLabel).

## محدوده تغییرات و ملاحظات
فقط ۳ فایل موجود (EditParking.jsx / EditParking.css / ParkingCard.jsx) جایگزین و ۳ فایل جدید (helper، آزمون، سند) اضافه می‌شود. به ثبت، قیمت، ذخیره‌سازی، بک‌اند، دیتابیس یا سرور اصلی دست زده نمی‌شود.

در بررسی ایستا، فهرست ۹ دسته در AddParking، ParkingDetails و ParkingCard مقایسه و متن‌های عمومی صفحه ویرایش تطبیق داده شد. این کار **ادعای تست عملی تمام فرآیندهای ثبت و ویرایش نیست**.

۳۸۲/۳۸۲ آزمون Node موفق، ۰ شکست؛ JSX با TypeScript parser بدون خطای نحوی. Build روی Windows و مشاهده مرورگر هنوز لازم است.

## مراحل تأیید در ویندوز
1. node --test tests/*.test.mjs
2. npm run build
3. npm run dev:all و Ctrl+Shift+R
4. ویرایش مغازه (عنوان و فاصله سربرگ)، سپس بررسی نمونه‌ای از دیگر دسته‌ها در عرضه و تقاضا؛ در موبایل نیز چیدمان.
5. پس از تأیید، Commit/Push.

## امنیت و بازیابی
INSTALL_EDIT_ALL_CATEGORIES.ps1 در ابتدای نصب، SHA256 فایل‌های جدید و نسخه مبنای فایل‌های فعلی را کنترل می‌کند. در صورت مغایرت، تغییری ایجاد نمی‌کند. بعد نسخه پشتیبان در Documents/Fazajoo_Patch_Backups می‌گیرد؛ RESTORE_EDIT_ALL_CATEGORIES.ps1 با BackupRoot بازگردانی محافظت‌شده را اجرا می‌کند. از این فایل‌ها هیچ کلید یا اطلاعات محرمانه‌ای خوانده یا بسته‌بندی نشده است.
