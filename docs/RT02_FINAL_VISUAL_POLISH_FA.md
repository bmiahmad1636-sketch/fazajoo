# فضاجو — اصلاح پایانی RT-02: ویرایش پارکینگ و بودجه تقاضای سایر فضاها

مبنای دقیق: `Fazajoo_FOR_CHATGPT(20261107-180335).zip`، آخرین ZIP دریافتی پس از نصب RT-02 UX.

## دو تغییر اصلی

۱) صفحه ویرایش **عرضه پارکینگ**: حذف هم‌پوشانی فرم با عنوان و متن راهنمای سربرگ با فاصله عمودی استاندارد در دسکتاپ و موبایل. با یک کلاس مستقل محدود شده؛ ویرایش درخواست‌ها و عرضه سایر دسته‌ها دست‌نخورده است.

۲) صفحه جزئیات **تقاضای سایر فضاها**: کارت بودجه بالا سمت چپ همان ردیف‌های مالی عرضه را استفاده می‌کند. برای رهن‌واجاره، ودیعه و اجاره ماهانه در سطرهای مستقل؛ برای رهن کامل بدون اجاره ساختگی؛ برای فقط اجاره بدون ودیعه ساختگی؛ برای کوتاه‌مدت همراه دوره نرخ. در «مشخصات اصلی» هم همان قالب منظم استفاده می‌شود. نمایش خطی بودجه تکراری از بخش مشخصات اختصاصی حذف می‌شود، ولی اطلاعات مالی اصلی در درخواست دست‌نخورده باقی می‌مانند.

## ایمنی و سازگاری

- ۴ فایل موجود جایگزین و ۲ فایل جدید (تست و سند) اضافه می‌شود.
- هیچ تغییری در بک‌اند، دیتابیس، ثبت آگهی، موتور خبرم کن، مدل داده یا VPS نیست.
- نصب‌کننده ابتدا SHA256 نرمال‌شده تمام فایل‌ها را با نسخه ZIP فعلی تطبیق می‌دهد، سپس نسخه‌های موجود را در Documents پشتیبان می‌گیرد.
- در صورت اختلاف مبنا نصب نکنید و فایل‌ها را دستی جایگزین نکنید؛ امکان بازگشت با RESTORE_RT02_FINAL.ps1 وجود دارد.
- قبل از تحویل بسته: ۳۶۸/۳۶۸ آزمون Node موفق، بررسی نحوی JSX موفق؛ **Build Vite ویندوز و بررسی ظاهری مرورگر هنوز نیاز به تأیید دارند**.

## نصب

فایل را بدون استخراج در Documents یا Downloads قرار بدهید. از ترمینال ریشه پروژه `Fazajoo_MAIN`، ZIP را استخراج و با این دستور اجرا کنید:

```powershell
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File (Join-Path $stage "INSTALL_RT02_FINAL.ps1") -ProjectRoot (Get-Location).Path
```

بعد از نصب:

```powershell
node --test tests/*.test.mjs
npm run build
```

پس از Build، سرور لوکال را از نو اجرا کنید، ویرایش پارکینگ و جزئیات درخواست «سایر فضاها» را در دسکتاپ و موبایل بررسی کنید. تا تأیید مرورگر Commit/Push نکنید.

## بازگردانی

نشانی فولدر Backup در خروجی نصب درج می‌شود. برای بازگردانی، از PowerShell پروژه:

```powershell
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File (Join-Path $stage "RESTORE_RT02_FINAL.ps1") -ProjectRoot (Get-Location).Path -BackupRoot "PATH_PRINTED_BY_INSTALLER"
```

اسکریپت بازگردانی پیش از هر تغییری هش فایل‌های فعلی را کنترل می‌کند تا تغییرات بعدی شما به اشتباه از بین نروند.
