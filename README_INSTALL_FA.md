# بسته اصلاح شعار فضاجو — Safe — 2026-11-14

## هدف
تعویض شعار صفحه اول فضاجو و حذف عبارت قبلی از محل‌های استفاده در سایت.

## شعار جدید اعمال‌شده
- «فضاجو؛ هر فضا، یک فرصت»

## فایل‌های موجود در این بسته
- `src/components/Hero.jsx`
- `src/components/Hero.css`

## تغییرات انجام‌شده
1. عنوان اصلی Hero از:
   - «فضای درست، برای نیاز واقعی تو.»
   به:
   - «فضاجو؛ هر فضا، یک فرصت»
2. متن زیر لوگو در Hero از:
   - «هر فضا، یک فرصت تازه.»
   به:
   - «هر فضا، یک فرصت»
3. استایل عنوان Hero بازطراحی شد تا نمایش شعار جدید زیباتر و حرفه‌ای‌تر باشد.
4. جستجوی پروژه نشان داد شعار قبلی فقط در همین بخش‌های Hero استفاده شده بود و همان‌ها اصلاح شدند.

## روش نصب
1. از پروژه فعلی خود بکاپ یا Snapshot داشته باشید.
2. دو فایل داخل این بسته را دقیقا روی مسیرهای همنام در پروژه جایگزین کنید.
3. سپس اجرا کنید:
   - `npm run build`
   - یا برای تست لوکال: `npm run dev`

## نکته
در محیط ابزار من به‌دلیل نصب نبودن وابستگی‌های فرانت، build نهایی قابل اجرای کامل نبود؛ اما تغییر فقط متنی/استایلی و محدود به همین دو فایل است.
